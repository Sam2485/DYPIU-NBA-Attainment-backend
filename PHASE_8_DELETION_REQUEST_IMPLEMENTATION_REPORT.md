## 1. Architecture Implemented

Phase 8 implements the hierarchical deletion request workflow and permanent soft-delete architecture for academic entities in the DYPIU NBA Attainment Backend.

```
WORKFLOW A: ProgrammeBatchCourse Deletion
-----------------------------------------
Programme Coordinator
        │
        │ POST /deletion-requests (resourceType=PROGRAMME_BATCH_COURSE)
        ▼
DeletionRequest (status = PENDING)
        │
        ▼
HOD Review
    ├── REJECT  ──► status = REJECTED (Remarks preserved, AuditLog: DELETE_REJECTED)
    └── EXECUTE ──► Requires HOD Account Password
                        │
                        ▼ (Password Verified via PasswordEncoder + Role Checked)
                    SOFT DELETE (deletedAt, deletedBy, status="DELETED")
                        │
                        ▼ (status = EXECUTED)
                    AuditLog: DELETE_APPROVED + DELETE_EXECUTED

WORKFLOW B: ProgrammeBatch Deletion
------------------------------------
HOD
        │
        │ POST /deletion-requests (resourceType=PROGRAMME_BATCH)
        ▼
DeletionRequest (status = PENDING)
        │
        ▼
Director Review
    ├── REJECT  ──► status = REJECTED (Remarks preserved, AuditLog: DELETE_REJECTED)
    └── EXECUTE ──► Requires Director Account Password
                        │
                        ▼ (Password Verified via PasswordEncoder + Role Checked)
                    SOFT DELETE (deletedAt, deletedBy, status="DELETED")
                        │
                        ▼ (status = EXECUTED)
                    AuditLog: DELETE_APPROVED + DELETE_EXECUTED
```

## 2. Architectural Invariants & Non-Negotiable Rules

1. **NO Physical Deletion / Hard DELETE**:
   - `repository.delete(...)`, `repository.deleteById(...)`, and native `DELETE FROM` SQL are strictly forbidden for academic entities.
   - Deletions are executed strictly as **soft deletion** by setting `deleted_at`, `deleted_by`, and `status = "DELETED"`.
2. **NO Purge / NO Permanent Data Destruction**:
   - There are zero background purge jobs, zero cascade deletions, and zero physical removals.
   - All historical academic records (POs, PSOs, PEOs, COs, CO-PO mappings, marks, surveys, attainments, ATRs, reports, and audit logs) remain permanently available indefinitely.
3. **Password-Confirmed Execution**:
   - Execution requires the reviewer's account password.
   - The password is authenticated server-side against the stored hash in `userRepository` via Spring Security's `PasswordEncoder`.
   - Passwords are **NEVER stored, logged, or recorded in audit metadata**.
4. **Actor & Role Scope Enforcement**:
   - Actor identity is derived strictly from `SecurityContextHolder`.
   - Self-approval/self-execution is blocked server-side (requester cannot review or execute their own deletion request).
   - Cross-scope protection: HOD can only review course offerings in their department; Director can only review batches in their school.
5. **Single Centralized Audit Trail**:
   - No duplicate `DeletionHistory` table created. All events (`DELETE_REQUESTED`, `DELETE_APPROVED`, `DELETE_REJECTED`, `DELETE_EXECUTED`) flow through the centralized [`AuditLogService`](file:///Users/rajshaikh/Desktop/DYPIU-NBA-Attainment-backend/obe-backend/src/main/java/com/dypiu/nba/service/AuditLogService.java).
   - `ADMIN` and `IQAC` retain exclusive access to read full audit logs.

## 3. Database Schema Changes (`V3__create_deletion_requests_and_soft_delete_schema.sql`)

```sql
-- 1. Soft Delete columns
ALTER TABLE programme_batches ADD COLUMN IF NOT EXISTS deleted_at TIMESTAMP WITH TIME ZONE;
ALTER TABLE programme_batches ADD COLUMN IF NOT EXISTS deleted_by VARCHAR(255);

ALTER TABLE programme_batch_courses ADD COLUMN IF NOT EXISTS deleted_at TIMESTAMP WITH TIME ZONE;
ALTER TABLE programme_batch_courses ADD COLUMN IF NOT EXISTS deleted_by VARCHAR(255);

-- 2. Deletion Requests table
CREATE TABLE IF NOT EXISTS deletion_requests (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    resource_type VARCHAR(100) NOT NULL,
    resource_id VARCHAR(255) NOT NULL,
    programme_batch_id VARCHAR(100),
    programme_batch_course_id VARCHAR(100),
    master_programme_id VARCHAR(100),
    department_id VARCHAR(100),
    school_id VARCHAR(100),
    status VARCHAR(50) NOT NULL DEFAULT 'PENDING',
    requested_by VARCHAR(255),
    requested_by_id VARCHAR(100),
    requested_by_role VARCHAR(50),
    requested_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    reviewed_by VARCHAR(255),
    reviewed_by_id VARCHAR(100),
    reviewed_by_role VARCHAR(50),
    reviewed_at TIMESTAMP WITH TIME ZONE,
    executed_at TIMESTAMP WITH TIME ZONE,
    remarks TEXT,
    rejection_reason TEXT,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_deletion_requests_resource ON deletion_requests(resource_type, resource_id);
CREATE INDEX IF NOT EXISTS idx_deletion_requests_status ON deletion_requests(status);
CREATE INDEX IF NOT EXISTS idx_deletion_requests_scope ON deletion_requests(school_id, department_id, master_programme_id);
CREATE INDEX IF NOT EXISTS idx_programme_batches_deleted ON programme_batches(deleted_at);
CREATE INDEX IF NOT EXISTS idx_programme_batch_courses_deleted ON programme_batch_courses(deleted_at);
```

## 5. API Endpoints

| HTTP Method | Endpoint Path | Description | Access Role |
|---|---|---|---|
| `POST` | `/deletion-requests` | Create deletion request (`PENDING`) | `PROGRAMME_COORDINATOR` (for Course Offering), `HOD` (for Batch), `ADMIN`, `IQAC` |
| `POST` | `/deletion-requests/{id}/reject` | Reject deletion request (`REJECTED`) | `HOD` (for Course Offering), `DIRECTOR` (for Batch), `ADMIN`, `IQAC` |
| `POST` | `/deletion-requests/{id}/execute` | Execute soft deletion with password | `HOD` (for Course Offering), `DIRECTOR` (for Batch), `ADMIN`, `IQAC` |
| `GET` | `/deletion-requests` | List scoped deletion requests | Authenticated (scoped by role/department/school) |
| `GET` | `/deletion-requests/{id}` | Get deletion request by ID | Authenticated |
