## 1. Executive Summary

Phase 7 implements a production-grade, centralized, immutable audit logging architecture for the DYPIU NBA Attainment Backend. The system maintains an institutional, permanent audit trail capturing the actor (strictly derived from Spring Security Context), operation action, resource type, affected resource instance, state transition, timestamps, and sanitized metadata.

## 3. Database Schema & Migration (`V2__create_centralized_audit_logs_schema.sql`)

```sql
CREATE TABLE IF NOT EXISTS audit_logs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    actor_id VARCHAR(100),
    actor_role VARCHAR(50),
    actor_name VARCHAR(255),
    actor_email VARCHAR(255),
    action VARCHAR(100) NOT NULL,
    resource_type VARCHAR(100) NOT NULL,
    resource_id VARCHAR(255),
    old_status VARCHAR(50),
    new_status VARCHAR(50),
    remarks TEXT,
    metadata TEXT,
    success BOOLEAN NOT NULL DEFAULT TRUE,
    ip_address VARCHAR(100),
    user_agent VARCHAR(500),
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_audit_logs_actor ON audit_logs(actor_id);
CREATE INDEX IF NOT EXISTS idx_audit_logs_action ON audit_logs(action);
CREATE INDEX IF NOT EXISTS idx_audit_logs_resource ON audit_logs(resource_type, resource_id);
CREATE INDEX IF NOT EXISTS idx_audit_logs_created_at ON audit_logs(created_at);
```

## 5. Security & Actor Resolution Invariants

- **Actor Source of Truth**: The actor details (`actorId`, `actorRole`, `actorName`, `actorEmail`) are extracted directly from `SecurityContextHolder.getContext().getAuthentication()`. Client-side forgery in request bodies or query parameters is strictly ignored.
- **Client IP & User Agent**: Automatically extracted from `HttpServletRequest` via `RequestContextHolder`.
- **Sensitive Data Redaction**: Automatic recursion and key scanning redacts passwords, password hashes, JWT tokens, refresh tokens, authorization headers, and secrets before saving metadata or remarks.
- **Role Scoping for Audit Access**:
  - `ADMIN` & `IQAC`: **Allowed (`200 OK`)**.
  - `DIRECTOR`, `HOD`, `PROGRAMME_COORDINATOR`, `FACULTY`: **Denied (`403 Forbidden`)**.
  - Unauthenticated requests: **Denied (`401 Unauthorized`)**.
- **Immutability**: Audit logs are append-only. There are NO `PUT`, `PATCH`, or `DELETE` endpoints for audit logs.
